# Projecte IA

L'estructura de fitxers del projecte és:
1. La carpeta src/ on guardem la implementació de totes les classes de l'AIMA
2. Els fitxers .jar necessaris per executar el program
3. El fitxer Main.java que executa el codi principal i instancia a les classes de l'AIMA

La compilació del programa es fa mitjançant el Makefile present al directori arrel.

## Compilar i executar (al directori arrel)

make run

## Netejar

make clean
